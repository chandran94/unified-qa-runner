## Implementation

- Added `qa.runner.port` support so isolated launches can use a non-production port.
- Added project ownership for shared paths (`SHARED_PATH`) and remote imports (`REMOTE_IMPORT`).
- New shared paths require an existing readable absolute directory and are canonicalized with `toRealPath()`.
- Asset discovery and execution include only project-owned shared/imported roots.
- Shared/import scan results reject files that resolve outside their canonical root.
- Legacy shared paths/imports are migrated as `UNRESOLVED` and remain admin-only.
- Added regression coverage for shared/import ownership quarantine and immutable assignment.
