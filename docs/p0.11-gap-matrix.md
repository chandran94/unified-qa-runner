# P0.11 Level 3 security gap matrix

| Area | Existing control | Gap before P0.11 | Required disposition |
|---|---|---|---|
| Authentication/session/CSRF | Session cookie, CSRF token, same-origin checks, logout invalidation | Existing controls require live verification | Preserve and verify |
| Team/RBAC | `TeamAuthorization` and role mutation guards | Existing controls require live verification of project-manager boundaries | Preserve and verify |
| Test cases, Wiki, stories | Project checks and ownership index for newly created records | Existing controls require regression verification | Preserve and verify |
| Attachments | Story relationship and normalized storage path | Read/download/delete did not independently enforce ownership | Add ownership checks to every operation |
| Reports/execution history | Run ownership is assigned from test case | Report/file artifact checks were incomplete; legacy runs can be unowned | Bind report/artifacts to run ownership; quarantine legacy |
| Screenshots/videos | Filename/path traversal checks | File names were treated as globally readable/deletable for admins only; no project ownership for new artifacts | Add artifact ownership index and project-filtered list/read/delete |
| Runner assets/shared paths/imports | Admin-only fallback | New records had no validated project relationship; execution could consume all configured paths | Require project ID on creation and carry it into discovery/execution |
| CI/CD configuration/history | Admin/role gate; encrypted token | Configuration and status were singleton/global and lacked authoritative project scope | Require project scope and enforce it on read/write/test/generate/status/commit |
| Legacy records | Additive migration and unresolved quarantine exists | Counts and review workflow were not exposed as a typed report | Add report endpoint/output and retain admin-only unresolved records |
| Live browser evidence | Local two-account harness exists | No shared browser page/credentials available in this session | Run only if existing local harness can provision disposable accounts without secrets |
